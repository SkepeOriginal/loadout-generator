# CS2 Wingman Loadout Randomizer

## Files
- index.html
- style.css
- script.js
- assets/

## How to use images
Put your own weapon images in the assets folder.

The file names should match the image paths in script.js.

Examples:
- assets/usp-s.png
- assets/ak-47.png
- assets/he-grenade.png

If an image is missing, the site will still work and show the weapon name as a fallback.
